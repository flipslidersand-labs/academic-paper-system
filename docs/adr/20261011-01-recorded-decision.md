## 背景

README の検索モードは hybrid・keyword・vector を明示し、語句一致と意味類似の両方を扱う。

## 記録する判断

論文チャンクを Qdrant と SQLite FTS5 に索引し、キーワード検索とベクトル検索の順位を RRF で統合する。

この ADR は既存資料・コードの判断を整理した遡及記録であり、今回の整備で新しい設計を承認・実装したものではない。設計資料にある将来案の実装完了は断定しない。

## 代替案と判断の根拠

## 影響と制約

二つの索引の更新整合性が必要になる。hybrid の品質は単独モードと同じ評価セットで比較する必要がある。

## 再検討する条件

チャンク・embedding モデル変更、索引不整合、評価で単独方式が優位になった場合。
